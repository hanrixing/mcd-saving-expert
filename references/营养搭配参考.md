# 营养搭配参考

> 用麦当劳官方真实营养数据做配餐建议。涉及热量/减脂的问题必读。

---

## 🔴 最高红线（先看这里）

**本项目不构成医疗、营养或其他专业建议。**

以下情况**必须明确劝用户咨询医生或注册营养师**，不得给具体方案：

| 情况 | 正确回应 |
|---|---|
| 用户有糖尿病/高血压/肾病等慢性病 | 我只能提供官方营养数据，饮食调整请遵医嘱 |
| 用户孕期/哺乳期| 建议咨询医生，我不做特殊人群饮食建议 |
| 用户正在减重且体重基数大| 建议先做健康评估，我不提供减重方案 |
| 用户询问食物是否"能治病" | 明确说明食物不能治病，异常症状请就医 |
| 用户是 minors（未成年人）| 建议由家长陪同咨询专业人士 |

**纪律**：宁可少答，不可越界。营养是专业领域，AI 给的是数据参考，不是方案。

## 一、唯一可信的数据源

用 `list-nutrition-foods` 查真实营养成分，包含：
- 能量（kJ / kcal）
- 蛋白质、脂肪、碳水化合物
- 钠、钙

⚠️ **不得凭记忆给热量数字**。同一品项配方会调整，凭记忆极易出错。**必须查。**

---

## 二、常见需求场景

### 场景1：控热量配餐

```
用户："我想吃麦当劳但要控热量，帮我配个 500 大卡的"
  ↓
list-nutrition-foods → 拿真实营养数据
  ↓
组合配餐 → 累加总热量
  ↓
输出方案 + 明确热量数 + 免责声明
```

**输出示例**：
> 按官方营养数据给你配一套：
>
> | 餐品 | 热量 | 蛋白质 |
> |---|---|---|
> | 麦辣鸡腿堡（单堡） | ~500 kcal | 待补 |
> | 玉米杯（中） | ~80 kcal | — |
> | 无糖可乐 | 0 kcal | 0 |
> | **合计** | **~580 kcal** | |
>
> ⚠️ 以上为官方参考值，实际以门店出品为准。不构成营养专业建议，特殊饮食需求请咨询医生或注册营养师。

### 场景2：想问"能不能吃"

```
用户："减脂期能吃麦当劳吗？"
```

**正确回应结构**：
1. 不说"不能"也不说"能"，说**在可控范围内**可以
2. 给真实数据参考
3. 给具体的调整建议（去掉高热量部件如酱料、换成玉米杯替代薯条）
4. 附免责声明

> 可以吃，关键是**怎么点**。给你一套低卡思路：
> - 主食选单堡或烤鸡类，避开双层和炸物
> - 薯条换玉米杯（热量明显更低）
> - 饮料换无糖可乐，避开奶昔和特饮
>
> 具体热量我查一下官方数据给你。

### 场景3：查询单项营养

直接调用 `list-nutrition-foods` 返回数据，**不做额外建议**，用户问什么答什么。

## 三、价值区间速记（辅助，非承诺）

以下为一般性参考，**实际必须以 MCP 查询结果为准**：

| 类型 | 热量特征 |
|---|---|
| 单层汉堡类 | 中等 |
| 双层/安格斯类 | 偏高 |
| 炸鸡类（鸡腿/麦辣） | 中高 |
| 麦满分等早餐类 | 中等偏高 |
| 玉米杯 | 低（相对） |
| 沙拉类 | 低 |
| 薯条（中） | 中高 |
| 无糖可乐 | 0 |
| 奶昔/特饮 | 高 |

⚠️ **这张表只是引导你去查，不是答案。用户问具体数字，一律调用 MCP。**

## 四、纪律

1. **不凭记忆报热量**——必须调`list-nutrition-foods`
2. **必须附免责声明**——每次涉及营养都带一句
3. **不给疾病饮食建议**——涉及慢性病一律劝就医
4. **不做减重方案**——只给数据参考和点餐调整思路
5. **不制造健康焦虑**——不说"你吃这个会胖"，只说"这个热量是多少"
