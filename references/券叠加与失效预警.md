# 券叠加与失效预警

> 券的正确使用顺序 + 过期预警机制。涉及优惠券的问题必读。

---

## 一、券的正确顺序（很多人顺序错了）

**错误做法**：直接点餐 → 结算时才想起有券。

**正确顺序**：领券 → 选品 → 结算。

麦当劳 MCP 的 `calculate-price` 会自动按最优组合计算优惠，所以**核心动作是"先领券再算价"**，而不是手动去凑。

---

## 二、券的类型与叠加逻辑

| 券类型 | 对应 Tool | 叠加关系 |
|---|---|---|
| 麦麦省平台券 | `available-coupons` / `auto-bind-coupons` | 优先用，门槛最低 |
| 门店专属券 | `query-store-coupons` | 与平台券通常不叠加，取最优 |
| 免配送费券 | `query-my-coupons` | 只影响配送费，可与商品优惠并存 |
| 积分兑换券 | `mall-create-order` | 需扣积分，非直接抵扣 |

**关键纪律**：
- **不要把满减和折扣直接相加**——系统按最优单选
- 免配送费券不占用商品优惠额度，可优先单独用
- 券的叠加最终由`calculate-price` 验证，**不要自己心算**

---

## 三、失效预警（本项目最有价值的主动服务）

券最大的浪费不是没领，是**领了忘用过期**。用 MCP 工具可以做真实的临期提醒：

### 检测逻辑

```
query-my-coupons → 读取券列表
  → 逐张比对有效期
    → 3 天内过期 → 高优先提醒
    → 7 天内过期 → 常规提醒
    → 有门槛未满足 → 提示"还差 X 元可用"
```

### 提醒话术

**临期券**：
> ⚠️ 你有 2 张免配送费券将在 **3 天后（10月12日）** 过期，建议本周用掉。

**门槛未满足**：
> 你有张"满45 减 8"的券，当前购物车 38 元，还差 **7 元**可用。要凑单吗？（建议：先看看你有没有本来就想买的东西，别为凑单买不需要的）

**闲置识别**：
> 你账户里有 5 张券从未使用过，占用了你的优惠额度。要不要看看有什么订单能用上？

---

## 四、领券的正确姿势

| 场景 | 动作 |
|---|---|
| 用户问"有什么券" | `available-coupons` 展示 → `auto-bind-coupons` 全领 → `query-my-coupons` 核对 |
| 用户要下单了 | 先 `auto-bind-coupons`，再 `calculate-price`，确保用到券 |
| 券过期了 | 如实说"这张已过期"，不要建议"下次注意"了事 |

**为什么优先用 `auto-bind-coupons`**：手动领券会漏。这条工具的价值不是"领券"，是"**保证不漏**"。

---

## 五、纪律

1. **券金额必须来自 `query-my-coupons`**，不得凭记忆说"应该有张 10 元券"
2. **过期券如实告知**，不要美化
3. **不催用户凑单**——券到期是事实，但凑单买不需要的东西是另一种浪费
4. **券的时效性极强**：所有券状态必须标注查询时间，"截至今天 14:30"
